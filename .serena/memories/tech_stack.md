# Tech Stack

- Language: C/C++ (C++11/C++14/GNU++11)
- Framework: Arduino Core on Espressif32 (PlatformIO `framework = arduino`)
- Microcontrollers: ESP32-2432S028R (`cyd_28r`), JC2432W328C (`cyd_28c`), ESP32-3248S035C (`cyd_35c`)
- GUI Engine: LVGL v8 (`lvgl`)
- Graphics & Touch: TFT_eSPI, XPT2046_Touchscreen, CST816 / GT911 (Wire)
- Theme: Catppuccin RGB565 (`catppuccin-rgb565`)
- Storage: ESP32 `Preferences` (NVS)
- Tooling: PlatformIO Core (`pio`), go-task (`Taskfile.yml`), Unity test framework
